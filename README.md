# AutoCurse

> **hate courseworks**

## Программный комплекс для создания балочной клетки

**AutoCurse** — программный комплекс для расчёта вариантов стальной балочной клетки и выбора оптимального решения по заданным параметрам.

## Функциональность

### Наполнение проекта

* Графический интерфейс для ввода исходных данных и просмотра результатов
* Статические и конструктивные расчёты
* Автоматическое оформление результатов в виде курсовой работы
* Формирование таблиц и математических формул
* Построение схем и эпюр
* Генерация документов в формате `.docx`

### Набор возможностей

* Генерация вариантов балочной клетки по заданным размерам
* Качественная визуализация схем вариантов балочной клетки
* Сбор нагрузок на всех этапах расчёта с формированием таблиц
* Расчёт толщины стального настила по условию жёсткости
* Построение эпюр внутренних усилий балки настила
* Построение расчётных и нормативных эпюр второстепенной балки
* Подбор двутавров по условию прочности на основе баз данных нормативных профилей
* Выполнение полного комплекса расчётов с необходимыми проверками
* Расчёт расхода стали для всех вариантов и формирование таблицы сравнения
* Автоматическое заполнение стандартных листов оформления курсовой работы
* Скачивание полного отчёта, отдельных этапов расчёта, схем и эпюр

### Особенности

* Генерация документа осуществляется программно с использованием заранее подготовленных конструкций текста и математических выражений, без использования исходных файлов-шаблонов.
* Алгоритм создания вариантов балочной клетки основан на формировании полного массива допустимых значений с учётом конструктивных ограничений и последующем случайном выборе неповторяющихся вариантов.
* Конструктивные решения принимаются в соответствии с действующими нормативными требованиями с использованием баз данных, в которых необходимые характеристики представлены в виде свойств объектов и элементов массивов.
* Построение эпюр моментов второстепенной балки выполняется с использованием универсальной формулы для балок, нагруженных равными, равномерно расположенными сосредоточенными силами.
* Для формирования математических формул в формате **OMML** в проекте разработана собственная микробиблиотека-конструктор математических выражений.

## Применённые технологии

* [`docx`](https://github.com/dolanmiu/docx) — генерация документов Microsoft Word
* [`FileSaver.js`](https://github.com/eligrey/FileSaver.js) — сохранение файлов на стороне клиента
* **HTML5 Canvas** — построение схем и эпюр
* **Shadow DOM** — изоляция компонентов интерфейса
* **Custom Elements** — создание переиспользуемых компонентов интерфейса
